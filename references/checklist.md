# 检查清单

## 快速版：十六条

改完一段，逐条问一遍。

1. 第一次读的人会在这一句停下吗？要读两遍的，写下原因。
2. 一句话只报一个结果。
3. 写了 more、higher，就写出和谁比。
4. significant 只用在差异、关联或检验上，不用在比例或平均数上。
5. this、these、the former、the name 这类词，指的东西在前一句之内吗？
6. 一个名字只指一样东西，普通词别撞上自己定义的术语。
7. 冒号只用来引出列表、引文、问题或定义。
8. 少用先否定再肯定的铺垫，带内容的否定留下。
9. 正文不用破折号连接分句。
10. 连着几句长度差不多、开头一样的，改掉一处。
11. 空的过渡词和段尾总结，能删就删，删不掉就换成具体内容。
12. 用自己和这个领域会用的词，能用常用词就不用生僻词。
13. 论文只写研究本身，不写论文是怎么改出来的。
14. 研究问题、引文、数字、自己的反思，不交给 AI 改。
15. 改完重读这一段和前一段，字数上限、段落长度这些硬指标再跑一遍。
16. 别人和 AI 的意见，先拿原文和数据对过，成立的才改。

## 完整版：66 条，每条一句话

详细的规则、例子和查法见 `patterns.md`，编号一致。标 ⚙ 的可以先用 `scripts/flag_candidates.py` 列出候选。

### 第一组　句子：读者读到这里要停下

| 编号 | 问题 | 一句话的规则 |
|---|---|---|
| P1 | 第一次读的人要读两遍 | 第一次读就要能懂；要读两遍的句子，说出原因再改 |
| P2 | 一句话装了两个结果 | 一句只报告一个结果 |
| P3 | 从句层层嵌套，或一句串起几个主张 | 不套几层从句；串起第二个主张时拆开 |
| P4 | 主语是抽象的东西，或名词堆在一起 | 让做事的人或物做主语，动作写成动词 |
| P5 | 花园路径 | 补上 that、介词或动词，让结构一眼清楚 |
| P6 | 指代词离它指的东西太远 | 所指在两句以前或有歧义，就直接写出来 |
| P7 | 读者不知道所指的名词 | the name 写成 the interest's name |
| P8 ⚙ | 比较缺了另一边 | 写出和什么比 |
| P9 ⚙ | 统计词挂错对象，或缺了名词 | 显著性只属于差异、关联或检验；写出 p value |
| P10 | 句尾拖着出处和建议 | 出处单独一句，或放到句首 |
| P11 | 引文和句子接不上 | 引文的代词有所指，语法接得上，描述和引文一致 |
| P12 | 一个词能读成另一个意思，或撞上文中的术语 | 换一个只有一种读法的词 |
| P13 | 评价词或含糊的说法代替了结果 | 写出发现了什么 |

### 第二组　词和术语：一个名字只指一样东西

| 编号 | 问题 | 一句话的规则 |
|---|---|---|
| P14 | 一样东西有两个名字 | 一个概念一个名字，正文、表格和图一致 |
| P15 | 一个词有两个意思 | 一个词一个意思，普通词不和构念名重名 |
| P16 | 数据的名字不准确 | 按参与者实际交上来的东西命名 |
| P17 | 样本里的人和泛指的角色混用 | 研究里的人叫 participants，泛指的角色另用一个词 |
| P18 | 自造的词和别扭的标签 | 用领域已有的词，只为新构念造词 |
| P19 | 作者和领域都不用的词 | 拿不准的词，先查范文和所引文献 |
| P20 | 术语先用后定义，经典理论没有解释 | 第一次出现时定义；经典理论第一次用时描述一句 |
| P21 | 缩写、简称、有名的模型没写全 | 第一次出现时写全称和作者 |
| P22 | 借来的专业词换了意思 | 只在原来的意思上用 |
| P23 | 名字跟着构念走，没有跟着测量走 | 按量表实际测的东西命名；构念和测量分开 |
| P24 | 能用常用词的地方用了生僻词 | 有常用词能保持原意就换 |

### 第三组　结论、数字和来源：说到证据为止

| 编号 | 问题 | 一句话的规则 |
|---|---|---|
| P25 | 引用的来源不支持这句话 | 打开原文核对每个引用 |
| P26 | 数字不能从数据重现，或前后不一致 | 用数据和脚本重算；不一致时先查来历 |
| P27 | 概括比结果说得宽、强或弱 | 说到证据为止，也要说足 |
| P28 | 因果、不显著和平均的说法不准 | 相关不说因果，不显著不说没有关系，平均写 on average |
| P29 | 计数被当成发现 | 计数只描述这个样本，先用文字回答 |
| P30 | 没检验过的设计被写成前提 | should 只出现在从结果推出的建议里 |
| P31 | 结果出现得太早 | 引言、文献、框架和方法部分不写结果，也不预设结果 |
| P32 | 统计术语没有解释，或加了先例没有的限定词 | 第一次出现时用平白的话解释 |
| P33 | 参与者引文和转写不一致 | 逐字引用，省略处加省略号，约定写在方法里 |

### 第四组　段落和整篇的结构

| 编号 | 问题 | 一句话的规则 |
|---|---|---|
| P34 ⚙ | 一段讲了两个主张，或太长 | 一段一个主张，120–150 词，最多 180 词 |
| P35 | 建立在后文之上 | 只用前面已经交代过的东西 |
| P36 | 段落开头接不上前一段 | 开头从前一段接过来，连接词有所指 |
| P37 | 推理少了一步 | 每一句都从前一句推出 |
| P38 | 开头讲文档，或以别人的结论开头 | 开头讲主题，先讲本研究再引别人 |
| P39 | 同样的内容出现几次 | 每种内容一个家，每个结果报告一次，再提时用指引 |
| P40 | 前后说法不一致，或旧说法没跟着改 | 改一处，找出所有还按旧状态写的句子 |
| P41 | 带来的疑问多于价值的内容 | 没有结果或论证依赖它，就删去或移到附录 |
| P42 ⚙ | 论文在讲自己是怎么写成的 | 不写时间顺序、对写法的评论、预先回应反驳 |
| P43 | 方法细节散在各处 | 谁、用什么工具，只在方法里交代一次 |
| P44 | 引言没有从空白一步步推到方法 | 每一步由上一步推出；结果只说方向和意义 |

### 第七组　语气和文风：读起来像机器写的

| 编号 | 问题 | 一句话的规则 |
|---|---|---|
| P57 ⚙ | 冒号代替了「因为」或句号 | 冒号只引出列表、引文、问题或定义 |
| P58 ⚙ | 「不是 A 而是 B」的对比句式 | 直接说是什么；承载内容的否定保留 |
| P59 ⚙ | 破折号 | 正文不用破折号连接分句 |
| P60 ⚙ | 句长差不多，或连续三句同一个句式 | 让句长有变化，打破无意义的排比 |
| P61 ⚙ | 空洞的过渡词和段尾总结 | 删去，或换成具体内容 |
| P62 | 附近重复的发现，镜像式的句子 | 一个发现说一次，不写等式一样的句子 |

| P64 | 编辑的文字盖住了作者的声音 | 保留作者的推理和具体的行动者 |
